# Rocky Linux 10 (Red Quartz) -- 最低硬件要求

Rocky Linux 10 专为企业级稳定性和现代硬件兼容性而设计。以下最低规格适用于**最小化服务器安装**。对于 GUI 或生产环境，建议使用更高的规格。

---

## 支持的 CPU 架构

根据 Rocky Linux 10.0 发布说明，Rocky Linux 10 官方支持以下架构：

- **x86_64-v3**（Intel/AMD 64 位 CPU，至少为 Haswell 或等效的 AVX 支持）
- **aarch64**（ARMv8-A 64 位）
- **ppc64le**（IBM Power，小端序）
- **s390x**（IBM Z 大型机）
- **riscv64**（RISC-V 64 位）

### CPU 功能要求

- **x86_64-v3** 需要 AVX、AVX2、BMI1/2 和 FMA，对应于 Intel Haswell 或更高版本，或 AMD Excavator 或更新版本。
- 较旧的 x86_64 版本（v1/v2）**不受支持**，除非由社区 SIG 重新构建。

---

## CPU（处理器）

- **1 GHz 64 位（x86_64-v3）** 或其他架构的等效配置
- 对于服务器、桌面或虚拟化用途，建议使用多核 CPU

---

## 内存 (RAM)

- **2 GB** 最低（文本模式安装）
- GUI 安装建议 **4 GB+**
- 生产工作负载或虚拟化建议 **4-8 GB+**

---

## 存储

- **10 GB** 最低磁盘空间
- 建议 **20 GB+** 以容纳更新、日志和应用程序
- GUI 安装：**40 GB+** 以确保足够空间

---

## 网络

- 至少一个可用的以太网或无线网络适配器
- 支持通过 NetworkManager 配置 DHCP 或静态 IP

---

## 显示（用于 GUI 安装）

- 通过 VGA、HDMI 或 DisplayPort 支持最低 **1024x768** 分辨率
- 最小化服务器安装不需要

---

## 介质访问

- USB 端口（用于 live USB 安装程序）或 DVD-ROM 驱动器
- 云安装支持基于 ISO 或 PXE 的安装方式

---

## 固件

- 支持 UEFI 或 BIOS 引导；**推荐使用 UEFI**
- 支持 Secure Boot（可能需要手动注册密钥）

---

## 虚拟化支持

- 支持虚拟环境（KVM、VMware、VirtualBox、Hyper-V）
- 建议安装客户机工具（如 open-vm-tools、qemu-guest-agent）以获得最佳性能

---

## 汇总表

| 组件       | 最低要求                                    |
|------------------|--------------------------------------------------------|
| **CPU**         | 1 GHz 64 位（支持 AVX 的 x86_64-v3）或 ARM/POWER/Z/RISC-V 等效配置 |
| **RAM**         | 1 GB（GUI 安装需 2 GB）                                    |
| **磁盘空间**  | 10 GB（建议 20 GB+；GUI 安装需 40 GB+）             |
| **网络**     | 以太网或无线适配器                           |
| **显示**     | 支持 1024x768 分辨率（仅 GUI 需要）                        |
| **介质访问**| USB 或 DVD-ROM                                         |
| **固件**    | UEFI/BIOS（推荐 UEFI）；Secure Boot 可选     |

---

## 按使用场景的推荐规格

### 最小化服务器

- CPU：1 核 x86_64-v3（或 ARM/POWER/Z/RISC-V）
- RAM：1 GB
- 存储：10-20 GB

### 带 GUI 的桌面

- CPU：2+ 核 x86_64-v3（或等效配置）
- RAM：2-4 GB
- 存储：20-40 GB

### 开发/生产服务器

- CPU：4+ 核
- RAM：4-8 GB+
- 存储：40 GB+（根据工作负载需求）

---

## 补充说明

- 始终为日志、软件包更新和备份分配额外的存储空间。
- 对于云环境或虚拟化环境，选择满足或超过上述规格的实例类型。
- 不支持从早期 Rocky 版本（如 8 或 9）升级到 Rocky 10——**需要全新安装**。
