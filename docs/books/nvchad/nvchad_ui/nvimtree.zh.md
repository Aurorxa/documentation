# NvimTree - 文件资源管理器

![NvimTree](../images/nvimtree_basic.png){ align=right }

一个编辑器要具备功能性，必须提供打开和管理我们想要编写或编辑的文件的支持。Neovim 在其基本安装中不提供文件管理功能。这由 NvChad 通过 _kyazdani42/nvim-tree.lua_ 插件实现。该插件提供了一个文件资源管理器，你可以通过键盘按键执行所有最常见的文件操作。要打开它，使用组合键 ++ctrl++ + ++"n"++，这仅在 _NORMAL_ 模式下可用，使用相同的组合键可以关闭它。

如果我们安装了 [Nerd Fonts](../nerd_fonts.md)，如截图所示，我们将拥有一个虽然是文本形式但能图形化展示文件树的文件资源管理器。

打开后，我们可以使用组合键 ++ctrl++ + ++"h"++ 向左移动和 ++ctrl++ + ++"l"++ 向右移动，从资源管理器窗口切换到编辑器窗口，反之亦然。

## 使用文件资源管理器

要处理项目的文件树，_NvimTree_ 提供了许多有用的管理快捷方式，包括：

- ++"R"++（refresh，刷新）执行对项目中包含文件的重新读取
- ++"H"++（hide，隐藏）隐藏/显示隐藏文件和文件夹（以点 `.` 开头）
- ++"E"++（expand_all，展开全部）从根文件夹（workspace）展开整个文件树
- ++"W"++（collapse_all，折叠全部）从根文件夹关闭所有打开的文件夹
- ++"-"++（dir_up，向上目录）允许你向上返回文件夹。此导航还允许你退出根文件夹（workspace）到你的主目录
- ++"s"++（system，系统）使用系统为该文件类型设置的默认应用程序打开文件
- ++"f"++（find，查找）打开交互式文件搜索，可应用搜索过滤器
- ++"F"++ 关闭交互式搜索
- ++ctrl++ + ++"k"++ 显示有关文件的信息，如大小、创建日期等
- ++"g"++ + ++"?"++ 打开帮助，包含所有预定义的快捷方式供快速参考
- ++"q"++ 关闭文件资源管理器

![Nvimtree Find](../images/nvimtree_find_filter.png){ align=right }

!!! note "注意："

    使用 ++"f"++ 执行的交互式搜索以及使用箭头 ++"&gt;"++ ++"&lt;"++ 导航时，都限制在 _NvimTree_ 当前所在的文件夹内。要对整个工作区进行全局搜索，你必须首先使用 ++"E"++ 打开整个文件树，然后使用 ++"f"++ 开始搜索。

搜索将 **NvimTree_1** 缓冲区带入 _INSERT_ 状态以便输入过滤条件。如果没有选择文件，退出搜索需要你首先使用 ++esc++ 将缓冲区返回 _NORMAL_ 状态，然后再使用 ++"F"++ 关闭搜索。

### 选择文件

要选择文件，我们必须首先确保我们处于 statusline 中用 **NvimTree_1** 标记的 _nvimtree_ 缓冲区中。为此，我们可以使用上述窗口选择键或 NvChad 提供的特定 ++space++ + ++"e"++ 命令，该命令将光标定位在文件树中。此组合是 NvChad 默认映射的一部分，对应于插件的 `:NvimTreeFocus` 命令。

为了在文件树中移动，我们使用 ++"&gt;"++ 和 ++"&lt;"++ 键，它们允许我们在树中上下移动，直到到达所需的文件夹。一旦定位，我们可以用 ++enter++ 打开它，用 ++"BS"++ 关闭它。

必须强调的是，使用 ++"&gt;"++ 和 ++"&lt;"++ 键的导航始终引用当前文件夹。这意味着一旦打开一个文件夹并在其中定位，导航将限制在该文件夹内。要退出文件夹，我们使用 ++ctrl++ + ++"p"++（parent directory，父目录）键，它允许我们从当前文件夹返回到我们打开编辑器时所在的文件夹，该文件夹对应于 statusline 右侧定义的 _workspace_。

### 打开文件

定位到所需文件夹并选择要编辑的文件后，我们有以下组合键来打开它：

- ++enter++ 或 ++"o"++ 在新缓冲区中打开文件，将光标放在文件的第一行
- ++tab++ 在新缓冲区中打开文件，同时将光标保持在 _nvimtree_ 中，例如当你想要一次打开多个文件时，这一点很有用
- ++ctrl++ + ++"t"++ 在新 _tab_ 中打开文件，可以与其他现有缓冲区分开管理
- ++ctrl++ + ++"v"++ 通过将缓冲区垂直分割为两部分来打开文件，如果已经有一个打开的文件，它将与新文件并排显示
- ++ctrl++ + ++"h"++ 与上述命令类似，但水平分割缓冲区

### 文件管理

像所有文件资源管理器一样，在 _nvimtree_ 中，你可以创建、删除和重命名文件。由于始终采用文本方式，你将没有一个便捷的图形小部件，但指示将显示在 _statusline_ 中。所有组合键都有确认提示 _(y/n)_，以便有机会验证操作，从而避免不当更改。这对删除文件尤为重要，因为删除是不可逆的。

修改文件的按键有：

- ++"a"++（add，添加）允许创建文件或文件夹，创建文件夹的方法是名称后跟斜杠 `/`。例如 `/nvchad/nvimtree.md` 将创建相应的 markdown 文件，而 `/nvchad/nvimtree/` 将创建 _nvimtree_ 文件夹。创建将默认在此时文件资源管理器中光标所在的位置发生，因此选择创建文件所在的文件夹必须提前完成，或者你可以在 statusline 中写入完整路径，在编写路径时可以使用自动完成功能
- ++"r"++（rename，重命名）从原始名称重命名所选文件
- ++ctrl++ + ++"r"++ 重命名文件而不考虑其原始名称
- ++"d"++（delete，删除）删除所选文件，如果是文件夹则删除文件夹及其所有内容
- ++"x"++（cut，剪切）剪切选择并将其复制到剪贴板，可以是文件或文件夹及其所有内容，使用此命令配合粘贴命令，你可以在树中移动文件
- ++"c"++（copy，复制）与前一个命令一样，将文件复制到剪贴板，但在原始位置保留原始文件
- ++"p"++（paste，粘贴）将剪贴板的内容粘贴到当前位置
- ++"y"++ 仅将文件名复制到剪贴板，还有两个变体：++"Y"++ 复制相对路径，以及 ++"g"++ + ++"y"++ 复制绝对路径

## 高级功能

虽然默认禁用，_nvimtree_ 集成了一些控制可能 _Git_ 仓库的功能。此类功能通过使用对基本设置的覆盖来启用，如[模板 Chadrc](../template_chadrc.md) 页面的覆盖部分所述。

相关代码如下：

```lua
M.nvimtree = {
    git = {
        enable = true,
    },
    renderer = {
        highlight_git = true,
        icons = {
        show = {
            git = true,
            },
        },
    },
    view = {
        side = "right",
    },
}
```

一旦启用了 _Git_ 功能，我们的文件树将为我们提供本地文件相对于 Git 仓库的实时状态。

## 总结

_kyazdani42/nvim-tree.lua_ 插件为 Neovim 编辑器提供了文件资源管理器，这无疑是 NvChad IDE 的基本构建块之一，所有常见的文件操作都可以在其中执行。它还集成了高级功能，但这些功能必须启用。更多信息可以在[项目页面](https://github.com/kyazdani42/nvim-tree.lua)上找到。
