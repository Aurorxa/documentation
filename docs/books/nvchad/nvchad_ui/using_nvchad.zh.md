# 使用 NvChad 编辑

本章将介绍一些 NvChad 特有的命令和一些标准的 Neovim（vim）命令。正如之前在 [NvChad UI](nvchad_ui.md) 中概述的，NvChad 命令设置在 `..nvim/lua/core/mapping.lua` 文件中，允许使用按键来执行有时非常长的复合命令。

所有序列都以一个主键后跟一个选项开始。四个主键是：

* leader = ++space++
* A = ++alt++
* C = ++ctrl++
* S = ++shift++

就像在 "NvChad UI" 文档中一样，我们将替换实际要输入的命令，而不是映射。

## 打开文件

要在编辑器中打开文件，我们可以使用各种方法。我们可以简单地从命令行开始，通过指定文件名：

```bash
nvim /path/to/the/file
```

或者使用 `nvim` 命令打开编辑器。

如果我们使用后一种方法，我们有几种可能性。我们可以使用命令 ++shift++ + ++":"++ ++"e"++ + ++space++（edit）后跟路径，或者通过命令后跟 ++tab++ 键来在缓冲区中打开文件。

这将从项目的根目录开始为我们显示所有可用的文件和文件夹。最好记住，当我们在文件打开命令中使用 ++tab++ 键时，我们可以从方便的下拉菜单中选择文件。一旦这个下拉菜单打开，我们通过反复使用 ++tab++ 键在其中继续导航。

![Command :e + tab](../images/e_tab_command.png)

最好记住，列出的每个命令都以 ++shift++ 开头，后跟 ++space++ 以及路径或 ++tab++ 键。以下是其他操作的列表：

* `:view` - 以只读模式查看文件，无法更改文件。对于保护关键文件非常有用。
* `:split` - 在水平分屏中打开文件。
* `:vsplit` - 在垂直分屏中打开文件。
* `:tabedit` - 在新标签中打开文件。

在以下示例中，我们使用 `:vsplit` 打开了文件。

![Vsplit Open](../images/vsplit_open.png)

由于 NvChad 开发者所做的工作，我们获得了另一种打开文件的方式，即使用 *nvim-telescope/telescope.nvim* 插件。

当与 *RipGrep* 结合使用时，此插件允许我们以交互模式搜索要打开的文件。通过输入我们要查找的文件的初始字符，该插件将忽略所有不匹配的文件并仅呈现与搜索匹配的文件。这允许非常流畅的搜索和打开过程。

要访问 telescope 的查找文件功能，我们需要在编辑器中处于 NORMAL 模式，然后输入：++shift++ + ++":"++ **Telescope fd**

![leader ff](../images/leader_ff.png)

## 使用编辑器

一旦文件打开，我们就可以开始编辑它。为此，我们需要切换到 INSERT 模式，通过按 ++"i"++（insert）键激活。Statusline 中的模式指示器应从 NORMAL 变为 INSERT，缓冲区中放置的光标也应从彩色矩形变为 `|` 管道符号。

现在，我们输入的所有字符将从光标位置开始插入到文档中。要在 INSERT 模式下移动光标，Nvchad 开发者设置了一些方便的映射，如下所示：

* ++ctrl++ + ++"b"++ 转到行首
* ++ctrl++ + ++"e"++ 转到行尾
* ++ctrl++ + ++"h"++ 向左移动一个字符
* ++ctrl++ + ++"l"++ 向右移动一个字符
* ++ctrl++ + ++"j"++ 转到下一行
* ++ctrl++ + ++"k"++ 转到上一行

学习所有组合需要一些时间，但一旦掌握，它们将使导航变得非常快。例如，如果我们想要编辑光标所在位置的下一行的末尾，我们可以使用 ++ctrl++ + ++"e"++ 到当前行的末尾，然后使用 ++ctrl++ + ++"j"++ 到下一行，就已经在添加更改的位置了。

文档中的导航也可以使用键盘上的方向键或鼠标完成。

### 文本选择

文本选择也可以使用鼠标完成，并且非常方便，但在本章中我们将使用传统的基于键盘的方法。

要选择文本，我们需要进入 VISUAL 模式。为此，我们必须首先退出 insert 模式并切换到 normal 模式，通过 ++esc++ 键完成。

一旦我们将光标放在我们要选择的部分的开头，使用 ++ctrl++ + ++"v"++ 键进入 V-BLOC（Visual Block）模式。现在用光标移动，我们将看到我们的选择将被高亮。此时，我们可以对所选文本部分进行操作。

如果我们想将选择复制到剪贴板，我们将使用 ++"y"++ 键。如果我们想删除它，使用 ++"d"++ 键。一旦操作完成，文本将不再高亮。想要了解可以在 Visual Mode 中执行的所有操作的概述，可以直接从编辑器查看帮助：++shift++ + ++":"++ **help Visual-Mode**。

![Help Visual Mode](../images/help_visual_mode.png)

### 文本搜索

要搜索，使用斜杠字符 ++"/"++ 后跟搜索键 `/search_key`，它会高亮所有找到的匹配项。要移动到下一个匹配项，使用组合 ++"/"++ + ++enter++。要移动到上一个匹配项，使用 ++"?"++ + ++enter++。

搜索完成后，可以使用命令 ++shift++ + ++":"++ **noh**（no highlight，取消高亮）取消高亮。

![Find Command](../images/find_command.png)

搜索可以比上面图示的更加复杂；可以使用通配符、计数器和其他选项。帮助命令（++shift++ + ++":"++ **help**）可用于查看更多选项。

## 保存文档

文件夹创建或修改后，首先使用 ++esc++ 退出 INSERT 模式，然后输入命令 ++shift++ + ++":"++ + ++"w"++（write）来保存，这将使用当前名称在当前位置保存文件。如果你想用另一个名称或在另一个位置保存文件，只需让命令后跟保存路径：

```text
:w /path/to/new/file_or_position
```

要保存并同时关闭编辑器，使用命令 ++shift++ + ++":"++ + ++"wq"++（write - quit）。

在本章中，我们向你介绍了编辑器。还有许多比此处描述的更高级的功能。这些功能可以在 [Neovim 帮助](https://neovim.io/doc/user/)页面上查阅，或通过在编辑器中输入以下命令 ++shift++ + ++":"++ + **help** 查看。
