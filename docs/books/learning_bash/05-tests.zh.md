# Bash - 测试

****

**目标**：在本章中，您将学习如何：

:heavy_check_mark: 使用返回码；  
:heavy_check_mark: 测试文件并比较它们；  
:heavy_check_mark: 测试变量、字符串和整数；  
:heavy_check_mark: 执行数值整数运算；  

:checkered_flag: **linux**, **script**, **bash**, **variable**

**知识点**：:star: :star:  
**复杂度**：:star: :star: :star:  

**阅读时间**：10 分钟

****

完成后，所有由 shell 执行的命令都会返回一个**返回码**（也称为**状态码**或**退出码**）。

* 如果命令正确运行，按惯例状态码将为**零**。
* 如果命令在执行过程中遇到问题，其状态码将具有**非零值**。导致这种情况的原因有很多：缺少访问权限、缺少文件、输入不正确等。

您应参考 `man 命令` 的手册来了解开发者提供的返回码的不同值。

返回码不是直接可见的，而是存储在一个特殊变量中：`$?`。

```bash
mkdir directory
echo $?
0
```

```bash
mkdir /directory
mkdir: unable to create directory
echo $?
1
```

```bash
command_that_does_not_exist
command_that_does_not_exist: command not found
echo $?
127
```

!!! note

    使用 `echo` 命令显示 `$?` 变量的内容时，必须在您要评估的命令之后立即执行，因为此变量在每次执行命令、命令行或脚本后都会更新。

!!! tip

    由于 `$?` 的值在每次命令执行后都会更改，最好将其值放入一个变量中，以便后续用于测试或显示消息。

    ```
    ls no_file
    ls: cannot access 'no_file': No such file or directory
    result=$?
    echo $?
    0
    echo $result
    2
    ```

也可以在脚本中创建返回码。为此，只需要向 `exit` 命令添加一个数字参数。

```bash
bash # to avoid being disconnected after the "exit 2
exit 123
echo $?
123
```

除了命令的正确执行之外，shell 还提供了对多种模式运行测试的能力：

* **文件**：存在性、类型、权限、比较；
* **字符串**：长度、比较；
* **数值整数**：值、比较。

测试的结果：

* `$?=0`：测试正确执行且为真（true）；
* `$?=1`：测试正确执行但为假（false）；
* `$?=2`：测试未正确执行。

## 测试文件类型

对文件使用 `test` 命令的语法：

```bash
test [-d|-e|-f|-L] file
```

或：

```bash
[ -d|-e|-f|-L file ]
```

!!! NOTE

    请注意，`[` 之后和 `]` 之前有一个空格。

文件测试命令的选项：

| 选项 | 说明                                                     |
|--------|-----------------------------------------------------------------|
| `-e`   | 测试文件是否存在                                        |
| `-f`   | 测试文件是否存在且为普通类型                  |
| `-d`   | 检查文件是否存在且为目录类型              |
| `-L`   | 检查文件是否存在且为符号链接类型          |
| `-b`   | 检查文件是否存在且为块设备特殊类型     |
| `-c`   | 检查文件是否存在且为字符设备特殊类型 |
| `-p`   | 检查文件是否存在且为命名管道类型（FIFO）      |
| `-S`   | 检查文件是否存在且为 socket 类型                 |
| `-t`   | 检查文件是否存在且为终端类型               |
| `-r`   | 检查文件是否存在且可读                       |
| `-w`   | 检查文件是否存在且可写                       |
| `-x`   | 检查文件是否存在且可执行                     |
| `-g`   | 检查文件是否存在且具有 SGID 设置                    |
| `-u`   | 检查文件是否存在且具有 SUID 设置                    |
| `-s`   | 测试文件是否存在且非空（大小 > 0 字节）      |

示例：

```bash
test -e /etc/passwd
echo $?
0
[ -w /etc/passwd ]
echo $?
1
```

一些 shell（包括 bash）创建了一个更现代的内部命令，提供比外部 `test` 命令更多的功能。

```bash
[[ -s /etc/passwd ]]
echo $?
1
```

!!! NOTE

    因此，本章剩余部分我们将使用内部命令。

## 比较两个文件

也可以比较两个文件：

```bash
[[ file1 -nt|-ot|-ef file2 ]]
```

| 选项 | 说明                                              |
|--------|----------------------------------------------------------|
| `-nt`  | 测试第一个文件是否比第二个文件新         |
| `-ot`  | 测试第一个文件是否比第二个文件旧         |
| `-ef`  | 测试第一个文件是否是第二个文件的物理链接 |

## 测试变量

可以测试变量：

```bash
[[ -z|-n $variable ]]
```

| 选项 | 说明                        |
|--------|------------------------------------|
| `-z`   | 测试变量是否为空     |
| `-n`   | 测试变量是否非空 |

## 测试字符串

也可以比较两个字符串：

```bash
[[ string1 =|!=|<|> string2 ]]
```

示例：

```bash
[[ "$var" = "Rocky rocks!" ]]
echo $?
0
```

| 选项 | 说明                                                   |
|--------|---------------------------------------------------------------|
| `=`    | 测试第一个字符串是否等于第二个              |
| `!=`   | 测试第一个字符串是否与第二个不同    |
| `<`    | 测试第一个字符串是否在 ASCII 顺序中位于第二个之前 |
| `>`    | 测试第一个字符串是否在 ASCII 顺序中位于第二个之后  |

## 整数比较

测试整数的语法：

```bash
[[ "num1" -eq|-ne|-gt|-lt "num2" ]]
```

示例：

```bash
var=1
[[ "$var" -eq "1" ]]
echo $?
0
```

```bash
var=2
[[ "$var" -eq "1" ]]
echo $?
1
```

| 选项 | 说明                                           |
|--------|-------------------------------------------------------|
| `-eq`  | 测试第一个数是否等于第二个       |
| `-ne`  | 测试第一个数是否与第二个不同 |
| `-gt`  | 测试第一个数是否大于第二个   |
| `-lt`  | 测试第一个数是否小于第二个      |

!!! Note

    由于 shell 将数值视为普通字符（或字符串），对字符的测试无论是否按数值处理，都可能返回相同的结果。

    ```
    test "1" = "1"
    echo $?
    0
    test "1" -eq "1"
    echo $?
    0
    ```

    但测试结果的含义并不相同：

    * 在第一种情况下，它意味着两个字符在 ASCII 表中具有相同的值。
    * 在第二种情况下，它意味着两个数字相等。

## 组合测试

测试的组合允许在一个命令中执行多个测试。可以多次测试同一个参数（文件、字符串或数值），或测试不同的参数。

```bash
[ option1 argument1 [-a|-o] option2 argument 2 ]
```

```bash
ls -lad /etc
drwxr-xr-x 142 root root 12288 sept. 20 09:25 /etc
[ -d /etc -a -x /etc ]
echo $?
0
```

| 选项 | 说明                                                |
|--------|------------------------------------------------------------|
| `-a`   | AND（与）：如果所有模式都为真，则测试为真。       |
| `-o`   | OR（或）：如果至少有一个模式为真，则测试为真。 |

使用内部命令时，推荐使用以下语法：

```bash
[[ -d "/etc" && -x "/etc" ]]
```

测试可以用括号 `(` `)` 分组以赋予它们优先级。

```bash
(TEST1 -a TEST2) -a TEST3
```

`!` 字符用于执行选项所请求的测试的反向测试：

```bash
test -e /file # 如果文件存在则为真
! test -e /file # 如果文件不存在则为真
```

## 数值运算

`expr` 命令用于执行数值整数运算。

```bash
expr num1 [+] [-] [\*] [/] [%] num2
```

示例：

```bash
expr 2 + 2
4
```

!!! Warning

    请注意在运算符号两侧留有空格。如果忘记，您将收到错误消息。
    在乘法的情况下，通配符 `*` 前面需要加上 `\` 以避免错误解析。

| 选项 | 说明            |
|--------|------------------------|
| `+`    | 加法               |
| `-`    | 减法            |
| `\*`   | 乘法         |
| `/`    | 除法商      |
| `%`    | 除法的模         |

## `typeset` 命令

`typeset -i` 命令将变量声明为整数。

示例：

```bash
typeset -i var1
var1=1+1
var2=1+1
echo $var1
2
echo $var2
1+1
```

## `let` 命令

`let` 命令测试一个字符是否为数字。

示例：

```bash
var1="10"
var2="AA"
let $var1
echo $?
0
let $var2
echo $?
1
```

!!! Warning

    `let` 命令在评估数字 `0` 时不返回一致的返回码。

    ```
    let 0
    echo $?
    1
    ```

`let` 命令也允许执行数学运算：

```bash
let var=5+5
echo $var
10
```

`let` 可以用 `$(( ))` 替代。

```bash
echo $((5+2))
7
echo $((5*2))
10
var=$((5*3))
echo $var
15
```
