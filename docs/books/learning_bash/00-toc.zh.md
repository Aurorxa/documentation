# 使用 Rocky 学习 Bash

在本节中，您将学习更多关于 Bash 脚本编程的知识，这是每个管理员迟早都要掌握的技能。

## 概述

Shell 是 Linux 的命令解释器。它是一个不属于内核的二进制文件，形成了额外的一层，因此得名 "shell"（外壳）。

它解析用户输入的命令，然后由系统执行。

有几种 shell，它们都共享一些共同特性。用户可以自由选择最适合自己的那一种。一些例子包括：

* **Bourne-Again shell** (`bash`)，
* **Korn shell** (`ksh`)，
* **C shell** (`csh`)，
* 等等。

`bash` 在大多数（所有）Linux 发行版中默认存在。它的特点是实用且用户友好。

Shell 也是一种**基础的编程语言**，得益于一些专用命令，可以实现：

* **变量**的使用，
* 命令的**条件执行**，
* 命令的**重复执行**。

Shell 脚本的优点是它们可以**快速**且**可靠**地创建，无需**编译**或安装额外的命令。一个 shell 脚本只是一个没有任何修饰的文本文件（无粗体、斜体等）。

!!! NOTE

    尽管 shell 是一门"基础"的编程语言，但它仍然非常强大，有时比编译不佳的代码还要快。

要编写一个 shell 脚本，只需要将所有必要的命令放在一个文本文件中。通过使该文件可执行，shell 会依次读取它，并逐一执行其中的命令。也可以将脚本名称作为参数传递给 bash 二进制文件来执行它。

当 shell 遇到错误时，它会显示一条消息来标识问题，但仍然继续执行脚本。但有一些机制可以在发生错误时停止脚本的执行。命令特定的错误也会显示在屏幕上或文件内部。

什么是好的脚本？它需要是：

* **可靠的**：即使在误用的情况下，其运行也是无瑕疵的；
* **有注释的**：其代码带有注释，以便于重读和未来的演变；
* **可读的**：代码适当缩进，命令之间有间隔……
* **可移植的**：代码可以在任何 Linux 系统上运行，依赖管理，权限管理，等等。
