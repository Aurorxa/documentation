# 许可协议

RockyLinux 为培训师或希望自学如何管理 Linux 系统的人提供 Linux 课程资料。

RockyLinux 材料根据 Creative Commons-BY-SA 发布。这意味着你可以在尊重作者权利的前提下，自由地分享和转换这些材料。

**BY**：**署名**。你必须注明原始作者的名字。

**SA**：**相同方式共享**。

- Creative Commons-BY-SA 许可协议：https://creativecommons.org/licenses/by-sa/4.0/

文档及其源文件可从以下位置免费下载：

- [https://docs.rockylinux.org](https://docs.rockylinux.org/)
- [https://github.com/rocky-linux/documentation](https://github.com/rocky-linux/documentation)

我们的媒体源文件托管在 github.com 上。你将在其中找到本文档创建版本所在的源代码仓库。

从这些源文件，你可以使用 [mkdocs](https://www.mkdocs.org/) 生成你自己的个性化培训材料。你可以在[此处](https://github.com/rocky-linux/documentation/tree/main/build_pdf)找到生成文档的说明。

> 我如何为文档项目做出贡献？

你可以在我们的 [git 项目主页](https://github.com/rocky-linux/documentation)上找到加入我们所需的所有信息。

祝大家阅读愉快，希望你们喜欢这些内容。
