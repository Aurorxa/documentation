# Open source：为何从不加连字符

## Open source 还是 open-source，争论已结束

曾经有一段时间，如果作为形容词用在名词之前，使用带连字符版本的 open-source 是可以接受的，但现在不再如此。原因是什么？Open source 已经作为一个复合名词（compound noun）成为词汇的一部分。将其用作形容词已不再是被认可的做法。词汇化（Lexicalization）是指一个词或短语成为语言（在此情况下是我们的技术语言）中已确立的一部分的过程。以下是 Open Source Initiative（开源促进会）对此的描述：

> "open source" 中的 "open" 一词并不具有字典中能找到的"开放"含义。相反，"open source" 还包含用户自由，即软件用户为任何目的使用软件时无需与权利所有者协商即可享受（使用/改进/分享/货币化）该软件。也就是说，这不仅仅是关于透明度。

你仍然会在互联网上找到一些来源告诉你，在名词前用作形容词时应该在 open source 之间加连字符。现实是 open source *是*一个复合名词，因此它永远不应被用作形容词。你明白了吧。

## 其他复合名词的例子

其他成为词汇一部分的复合名词例子包括：

* high school
* green card
* yellow journalism

这些都是复合名词。很容易看出为什么是这样。它们作为独立词汇时的含义与组合在一起时的含义不同。*Yellow* 和 *journalism* 分开时含义不同。*Yellow* 是光谱中介于绿色和橙色之间的一种颜色。*Journalism* 是为杂志、新闻或网络资源写作的活动或职责。**但是** *yellow journalism*（黄色新闻）是一种利用煽情和夸张手法的新闻类型。它是一个名词。

这些不属于我们的技术词汇范畴，但很容易看出它们与 open source 的关联——后者是技术词汇。

## 结论

如前所述，你会找到支持在 open source 中使用连字符的资料（如果形容词规则适用的话），所以这归根到底是一个项目做出决定并坚持执行的问题。就 Rocky Linux 文档项目而言，我们认为你永远不应该将 "open source" 用作形容词。我们选择**仅**将其用作复合名词，遵循 Open Source Initiative 的范例。通过这样做，我们消除了争议，并减轻了文档编写者在编辑或创作时的压力，消除了疑问。目标是保持简单和清晰。
