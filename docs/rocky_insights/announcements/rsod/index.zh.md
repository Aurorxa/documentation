## 介绍

Rocky 文档之夏 (RSOD) 是一个始于 2024 年夏季的计划。基于 Google Summer of Code 的理念，RSOD 鼓励新的和现有的文档贡献者根据文档团队的特定目标添加文档。希望此计划能够每年持续举办。

如果您对未来的 RSOD 项目有建议，我们非常乐意听取您的意见。您可以通过 [文档团队 Mattermost 频道](https://chat.rockylinux.org/rocky-linux/channels/documentation) 与我们联系。
