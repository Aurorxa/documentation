# 实验 3: 系统管理工具

!!! info

    输入命令 `lab3-system_utilities`，启动一个名为 `lab3-system_utilities` 的 `tmux` 会话。更多信息请参见 [tmux helper scripts](../../../tools_scripts/lab_helpers.md)。

    在本实验中，你将深入了解命令行。你将探索 Linux 发行版中提供的一些常见的系统命令和实用程序，这些工具在你探索 Linux 服务器时会经常用到。

    !!! knowledge "知识要点"

        如果说在之前的实验中你都是在浅水区学习游泳，那么此前的实验你已经过了踩水的阶段。现在，请进入深水区，通过强化使用 Linux 系统上可用的系统和用户实用工具来真正掌握你的 Linux 技能。

        这一点怎么强调都不过分——在本实验中你将学到的东西，构成了你得心应手驾驭 Linux 系统的**基本**工具。你最终将：

        * 深入了解一些繁重的工作并熟悉每个工具
        * 掌握命令行管道、重定向、错误处理和其他复杂命令的执行流程

## 目标

1. 使用在 Rocky Linux 上可用的命令行工具
2. 学习使用一些常见的系统实用程序
3. 学习使用一些用户工具和文本处理程序
4. 能够在你的职业生涯中独立进行探索和使用其他实用程序

* 1 台安装了 Rocky Linux 的机器

* 你需要选择一款你喜欢的编辑器（vi、vim、nano）来编辑文件

## 常见的进程和系统管理工具

完成以下任务：

1. 使用最基本的形式运行 `top` 命令。观察输出几分钟，然后描述你所看到的内容。
2. 现在运行 `top` 命令，但只显示用户 `root` 拥有的进程。
3. 创建两个交互式的后台作业。一个使用 `sleep`，另一个使用 `watch`——用它们来做一些有点用处的事情。将作业置于后台。
4. 列出你的活动作业。将最近的一个从后台调到前台，然后将其恢复为在后台继续运行。
5. 使用 `nice` 命令创建两个具有不同调度优先级的相同类型的作业。
6. 以人性化格式列出所有进程："ps aux"。
7. 如何使用 `pgrep` 查找特定进程？
8. 如何使用 `pstree` 查找某进程及其所有子进程？
9. 检查过去 24 小时内谁登录过你的系统。提供命令和输出。对于正在登录的用户，他们正在运行什么程序？
10. 导出 shell 变量以显示称为提示符 2 (`PS2`) 的辅助输入提示符。例如，当你输入一个需要后续在不完整命令后继续输入的命令续行或更多输入时显示的提示符。

## 文件、文本和系统监控

完成以下任务：

1. 在你的系统上搜索属于特定用户的任何文件。
2. 使用 `wc` 显示文件的行数、字数和字符数。
3. 仅使用 `head` 和 `tail` 显示文件的前 3 行和后 3 行。
4. 解释 `stat` 命令的作用并演示其用法。
5. 使用 `sort` 和 `uniq` 从文件中删除重复行。
6. 使用管道连接 `awk` 和 `grep`，提取特定日志条目中的时间戳和错误信息。创建自己的日志示例，或伪造一个样本来执行此操作。
7. 使用 `tee` 在终端上显示命令输出，同时将输出写入文件。
8. 使用 `cut` 命令仅从 `/etc/passwd` 文件中提取用户名和主目录行。
9. 如何在 `/var/log` 中查找过去 48 小时内修改过的特定类型（例如 ".log"）的日志文件？使用 `find` 命令。
10. 创建 `/etc/hosts` 文件的备份并压缩。完成后，解压备份文件。使用 `sha1sum` 生成原始文件的校验和并与你的备份进行比较。
11. 使用 `tac` 命令以倒序显示文件内容。
