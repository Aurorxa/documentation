# 实验 5: 网络基础

!!! info

    输入命令 `lab5-networking`，启动一个名为 `lab5-networking` 的 `tmux` 会话。更多信息请参见 [tmux helper scripts](../../../tools_scripts/lab_helpers.md)。

    在本实验中，你将深入了解 Linux 网络。你将学习 Linux 网络堆栈、配置网络接口的基础知识，以及与在 Rocky Linux 服务器上使用的基本网络概念和工具进行实践。

    !!! knowledge "知识要点"

        本实验将带你从零开始，逐步掌握基于 Linux 的计算机网络基础。在本实验结束时，你将能够：

        * 在你的系统上配置网络接口和`绑定`（bonding）。现代 Linux 发行版使用 `NetworkManager` 作为默认网络管理工具。你将探索如何使用 `nmcli` 工具来管理系统网络、处理网卡绑定，并可以深入研究绑定接口的配置细节。

        * 使用 `nmcli` 和其他工具配置网络接口

        * 使用虚拟局域网（VLAN）

        * 使用基本的 IP 路由

## 目标

完成本实验后，你应该能够：

* 配置系统主机名的不同表示形式
* 配置网络绑定
* 配置 VLAN 设备
* 配置基于策略的路由

## 先决条件

在开始实验之前，你需要：

* 1 台安装了 Rocky Linux 的机器
* 至少 2 个网络接口（NIC），用于练习绑定和 VLAN
* 具有 root 访问权限或 sudo 凭据
* 了解你网络的基本情况：IP 寻址方案、VLAN ID（如果需要的话）

## 一些前置工作

1. 使用 `ip` 命令检查你当前的活动网络接口。注意输出中的设备名称和状态。
2. 检查你的默认网关和路由表。
3. 在系统上，验证 DNS 相关设置是否正确。
4. 至少验证以下每个网络端口的连接性。使用能够与这些端口建立连接的工具，例如 `nc` 或 `ncat`：

    * 80 (HTTP)
    * 443 (HTTPS)
    * 53 (DNS)
    * 22 (SSH)

        2. 如何在 Rocky Linux 上更改系统的 DNS 设置？
        3. 你使用什么命令来测试外部服务器上端口 80 的连接性？

## 配置网络接口

### 配置主机名

1. 配置三种不同表示形式的主机名：静态（static）、灵活（pretty）和临时（transient）。

    !!! question "问题"

2. 观察修改主机名后 `/etc/hostname` 文件内容的变化。

    !!! question "问题"

        1. 你可以编辑哪个文件来确保机器的主机名在启动时从该文件读取，而不是被其他设置覆盖？
        2. 如何配置多个备用 DNS 服务器？

### 配置网络绑定

网络绑定允许多个网络接口聚合成一个逻辑接口，以提高吞吐量或提供冗余。以 root 用户身份，使用 `nmcli` 命令完成以下任务。

1. 创建绑定接口：
    * 创建一个名为 `bond0` 的绑定接口。
    * 为其分配 IP 地址 `192.168.100.100/24`。
    * 绑定模式设置为 `active-backup`（主备模式）。

2. 将至少一个物理网络接口作为从属（slave）添加到绑定中。

    !!! question "问题"

        将接口添加到绑定接口时，`nmcli` 命令是什么？写出完整的命令。

3. 通过检查绑定接口的状态来验证绑定的设置。

    !!! question "问题"

        `/proc/net/bonding/bond0` 文件包含什么信息？

4. 打开另一个与 `bond0` 不在同一网络的其他活跃接口，通过 ping 测试连接性。

5. 练习使用绑定接口：

    * 使用 `nmcli` 或 `ip` 命令将绑定接口关闭，然后再恢复。
    * 从绑定中移除从属接口，然后重新添加回来。

    !!! question "问题"

        1. 解释每种绑定模式，特别是 0、1 和 4 之间的区别。
        2. 在 `active-backup` 绑定模式下，如果主接口（活跃接口）故障，哪个从属接口会成为新的主接口？

### 配置 VLAN 设备

VLAN（即虚拟局域网）允许你在单个物理接口上创建虚拟接口，每个接口拥有自己的 IP 地址。使用 `nmcli` 命令：

1. 在现有物理接口上创建一个 VLAN 设备（例如，`eno1`，VLAN ID = 10）。
2. 为其分配 IP 地址 `10.10.10.100/24`。
3. 启动 VLAN 设备。
4. 验证 VLAN 接口是否已配置并处于活动状态。
5. 删除 VLAN 接口。

    !!! question "问题"

        1. 你使用了什么命令序列来创建 VLAN 设备？
        2. 如何删除 VLAN 接口？
        3. 在运行 Rocky Linux 的 Linux 系统上，哪些类型的配置文件用于存储 VLAN 设备的配置？

### 基于策略的路由

1. 在你的 Rocky Linux 系统上创建一个临时网络命名空间，将其命名为 `net_temp`。
2. 运行这些命令以在该命名空间中验证连接性。例如，ping 命名空间中和命名空间外的接口：

    ```bash
    ip netns exec net_temp <其他命令>
    ```

3. 实验结束后，删除你创建的网络命名空间。
