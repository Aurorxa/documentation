本文档从 QA / 测试工作的角度总结了 Rocky Linux 9.0 发布的 GO / NO GO 状态。它主要基于发布标准 (<https://wiki.rockylinux.org/team/testing/release_criteria/>)，最初是从该文档导入的。如果正式发布标准文档与本文档之间存在差异，以正式发布标准文档为准，本文档应随之更新。

提醒一下，发布（主版本或次版本）的目标是提供一个稳定可靠的企业级 Linux 版本，适用于：

- 满足最终用户的需求
- 满足大小企业的需求

## 标准操作流程 (SOP)

本文档中描述了每项要求，并在标题中指定状态。

当前选项有...

### TO_CONFIRM（待确认）

- 表示该项目可能为 INCOMPLETE、PASS、FAIL_NON_BLOCKING 或 FAIL_BLOCKING，必须进行验证

### PASS（通过）

- 表示发布标准已满足，不是阻塞项

### FAIL_NON_BLOCKING（失败但非阻塞）

- 表示发布标准未满足，但不阻塞发布

### FAIL_BLOCKING（失败且阻塞）

- 表示发布标准未满足且阻塞发布

在本文档中，标准状态应包含完成该项目的人员及总体完成方式。
