# Rocky Linux 9.8 发布说明

## 总结

Rocky Linux 9.8 现已发布，适用于以下架构：

- AMD/Intel (x86_64)
- ARM64 (aarch64)
- IBM Power10 (ppc64le)
- IBM Z (s390x)

此版本包含重要的改进和安全更新，以及各种错误修复。

Rocky Linux 9.8 来源于 [Red Hat Enterprise Linux 9.8](https://access.redhat.com/documentation/en-us/red_hat_enterprise_linux/9/html/9.8_release_notes/index)，并包含了我们所做的修改。

## 亮点

### 新功能和显著变化

9.8 版本包含了几个新功能和显著变化。有关此版本的更多信息，请参阅 [官方发布说明](https://docs.rockylinux.org/release_notes/9_8/)。

#### 重要变化

以下是此版本中一些最重要的新增功能和变化概述：

- 作为蓝光激光（bluesky）和 `nvme-cli` 的一部分，虚拟 NVDIMM 设备现在可以作为直写（write-through）缓存设备使用，需要安装 `ndctl`。
- 用于 PTP 驱动程序的 `idletime` 和 `util semaphore` 过滤器现在已可用。
- 双密钥文件支持现在已可用，适用于磁盘加密。自定义策略可用于 LUKS1，使用 Clevis 执行自动解锁。查看 `nbde_client` 角色，并添加支持变量 `clevis_luks_policy_encryption_type`。
- clang 资源目录现在是 clang 的一个内置搜索路径。你现在可以为编译器构建自己的 RPM，无需为 clang 包含资源文件。
- SWIG 4.3.0 现在在 Rocky Linux 9.8 中可用，但它是新的模块流 `swig:4.3` 而不是默认版本。
- AMD 第四代 EPYC 9005 Turin 处理器现在得到全面支持。
- 同时支持 stunnel 5.62 和 5.71，用户可以使用新的 `stunnel:5.71` 模块流选择较新的版本。
- 包含 webkit 2.48 的 webkit2gtk3 现在可用。作为更新的一部分，捆绑的 ga 也已更新到 4.0。
- 在 `nodejs:22` 模块流中，也提供了 node.js 22 LTS。
- 已安装的 `/etc/os-release` 文件包含一组有限的 `VARIANT_ID`，以符合常见标准。`ID_LIKE` 字段现在除了 `fedora` 外也包含 `rhel`。当需要兼容性时，设置 `ID_LIKE="rhel fedora"` 就可以了！（我们希望世界不要停止运行）。

#### 镜像构建器

Rocky Linux 9.8 为 `osbuild-composer` 镜像构建器工具添加了多项改进：

- 用户现在可以将分区模式设置为 `auto-lvm`，这会自动为文件系统创建尽可能多的分区，并将挂载点分配为 LVM 逻辑卷。
- 用户可以通过自定义配置和蓝图文件包含额外的安装程序选项。
- 新选项允许用户控制 TLS 证书的强制使用，并且还有一些选项可以简化 AWSCLI 安装。
- 现在支持将构建的 QCOW2 镜像直接上传到 GCP。

#### 安全

安全相关的亮点包括：

- OpenSSH 已升级到 8.7p1-45，修复了 "regreSSHion" [CVE-2024-6387](https://access.redhat.com/security/cve/CVE-2024-6387) 和 CVE-2024-6409 漏洞，这是一个信号竞争条件问题。它还解决了 `ObscureKeystrokeTiming` 问题。
- SELinux 策略现在要求 MCS 在 GPFS（或任何不是 *t* 或 *tmpfs_t* 类型的文件系统）上的所有操作中都能正常工作。
- SCAP 安全指南 0.1.75 包含新的合规规则，支持 STIG 安全配置文件，开始支持两个 ANSSI 配置文件（BP28 High、BP28 Minimal），还有一个新的 CCN-STIC 配置文件。
- Rsyslog 现在支持 TLS/SSL 加密日志传输，支持多个证书文件和 CA，并且可以验证 X.509 名称。
- Libreswan 现在与 MLS 环境兼容，并集成了多个 `labeledipsec` 修复。还添加了新的 `leftid` 和 `rightid` 选项，提高了与第三方设备的连接兼容性。
- 支持 `fapolicyd` 规则中的 `uid` 和 `gid` 值，并与 `/etc/group` 文件集成。
- IdM 增加了对 CRMFRest API 版本 2 的支持，为自动化环境中的智能卡预发布提供 web UI 支持。

#### 动态编程语言、Web 服务器和数据库服务器

此版本中的新增功能包括：

- Python 3.12 和 Python 3.13 现已可用（作为新模块）。
- Node.js 22 现已可用（作为新模块）。
- Rust Toolset 1.84（作为新模块）。
- LLVM Toolset 19.1.7（作为新模块）。
- Nginx 1.28 现已可用（作为新模块）。
- MariaDB 10.11.11（作为新模块）。
- PostgreSQL 16（作为新模块）。
- Git 2.49（作为新模块）。
- Git LFS 3.6.1（作为新模块）。
- Redis 7.4（作为新模块）。
- Grafana 10.2.6（作为新模块）。
- Valkey 8.1 现已可用（作为新模块）。

## 已知问题

与任何发布一样，也存在一些已知问题，你可以在 Rocky Linux 9.8 发布版本的 [Issue Tracker](https://bugs.rockylinux.org/) 中找到。

这些已知问题的主要来源是 RHEL 的上游版本，部分问题可能是 Rocky Linux 独有的。

### 静态 IP 配置的额外说明

对于 Rocky Linux 9.8，如果你在系统安装期间或之后使用静态 IP 地址进行网络配置，可能会丢失网络连接。新增的 `auto_configuration` 选项在默认情况下会忽略静态 IP 配置，因此即使指定了静态网络，以太网连接也不会启用。解决方法是编辑网络配置，添加 `auto_configuration false`。
