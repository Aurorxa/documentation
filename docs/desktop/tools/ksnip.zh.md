## 前提条件与假设

- Rocky 9.4 Workstation
- `sudo` 权限

## 简介

Ksnip 是一款截图工具，提供多种标注截图的功能。本指南重点介绍 Ksnip 的安装及其标注工具。

## 安装 Ksnip

Ksnip 需要 EPEL 仓库。如果尚未启用 EPEL，可以通过以下命令启用：

```bash
sudo dnf install epel-release
```

然后执行系统更新：

```bash
sudo dnf update -y
```

现在安装 Ksnip：

```bash
sudo dnf install ksnip -y
```

## 打开图像

1. 打开 Ksnip
2. 点击 `File > Open`
3. 选择要标注的图像

![ksnip](images/ksnip.png)

## 使用 Ksnip 标注图像

Ksnip 拥有便捷直观的工具来标注截图。左侧垂直排列的选项如下所述。

![ksnip_open](images/ksnip_image_opened.png)

| 选项 | 工具 | 描述                                                                                         |
|------|------| --------------------------------------------------------------------------------------------|
| 1  | `Select` | 选择工具，用于创建选区。点击项目选中，或点击并拖动创建选区。 |
| 2  | `Duplicate` | 复制工具，用于复制选区。点击并拖动创建选区，然后点击并拖动选区进行移动或变换。|
| 3a | `Arrow`  | 默认箭头工具，点击并拖动从一处到另一处创建箭头。 |
| 3b | `Double Arrow` | 第二箭头选项，通过点击箭头工具旁的下拉箭头访问。如其名，两端都有箭头。 |
| 3c | `Line`   | 第三选项，通过点击箭头工具旁的下拉箭头访问。将箭头替换为简单线条。 |
| 4  | `Pen`    | 模拟钢笔笔触。使用钢笔时，按住点击并在截图上移动光标。 ^1^ |
| 5a | `Marker Pen` | 默认标记笔工具，模拟荧光笔效果。按住点击并在截图上拖动光标。 ^1^ |
| 5b | `Marker Rectangle` | 第二标记选项，通过点击标记工具旁的下拉箭头访问。左键点击并拖动光标时，标记矩形工具将填充所选区域形成的矩形。 ^1^ |
| 5c | `Marker Elipse`  | 第三标记选项，通过点击标记工具旁的下拉箭头访问。左键点击并拖动光标时，标记椭圆工具将填充所选区域形成的椭圆。 ^1^ |
| 6a | `Text` | 默认文字工具，允许用文本标注截图。 ^1^ |
| 6b | `Text Pointer` | 第二文本选项，通过点击文本工具旁的下拉箭头访问。附加一个指示器以吸引对文本的注意。 ^1^ |
| 6c | `Text Arrow` | 第三文本选项，通过点击文本工具旁的下拉箭头访问。附加一个箭头以吸引对文本的注意。 ^1^ |
| 7a | `Number`  | 默认编号工具，添加数字以吸引注意并用数字标注截图。 ^1^ |
| 7b | `Number Pointer` | 第二选项，通过点击编号工具旁的下拉箭头访问。添加带指示器的数字以进一步标注截图。 ^1^ |
| 7c | `Number Arrow` | 第三选项，通过点击编号工具旁的下拉箭头访问。添加带箭头的数字以进一步标注截图。 ^1^ |
| 8a | `Blur`  | 默认模糊工具，左键点击并拖动以模糊截图的某些部分。 |
| 8b | `Pixelate` | 第二模糊工具选项，通过点击模糊工具旁的下拉箭头访问。左键点击并拖动以像素化截图的任意位置。 |
| 9a | `Rectangle` | 默认矩形工具，点击并拖动创建矩形。 ^1^ |
| 9b | `Ellipse` | 第二矩形工具选项，通过点击矩形工具旁的下拉箭头访问。点击并拖动在屏幕上创建椭圆。 ^1^ |
| 10 | `Sticker` | 在截图上放置贴纸或表情符号。选中工具后点击即可放置贴纸。 |

## 结语

Ksnip 是一个出色的截图标注工具。它也可以截图，但本指南主要聚焦于 Ksnip 提供的标注功能和工具。

查看 [Ksnip GitHub 仓库](https://github.com/ksnip/ksnip){target="_blank"}，进一步了解这款优秀的截图工具。

**1.** 所有描述后带有 ==此上标== (^1^) 的工具，在做出工具选择后，顶部菜单中都会提供各种命令选项，用于调整透明度、边框、字体、字体样式和其他属性。
