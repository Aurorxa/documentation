## 简介

Rocky Linux 所搭载的现代 GNOME 桌面内置了功能强大且无缝集成的屏幕捕捉工具。这并非需要单独安装的独立应用程序，而是桌面 Shell 的核心组成部分，提供了流畅高效的方式来截图和录制短视频（录屏，Screencast）。

本指南介绍如何使用交互式用户界面和强大的键盘快捷键来捕获屏幕内容。

## 使用交互式截图界面

最简单的入门方式是使用交互式叠加层，它让您完全掌控捕捉的内容和方式。

1. **启动工具：** 按下键盘上的 `Print Screen`（通常标注为 `PrtSc`）键。屏幕将变暗，截图界面随之出现。

2. **了解界面：** 屏幕中央的控制面板包含三个主要区域：
    * **捕捉模式：** 左侧可选择捕捉矩形 `Region`（区域）、整个 `Screen`（屏幕）或特定 `Window`（窗口）。
    * **操作切换：** 中间可切换截取 **Screenshot**（截图，相机图标）或录制 **Screencast**（录屏，摄像机图标）。
    * **捕捉按钮：** 右侧的大型圆形按钮用于执行捕捉。

### 截图

1. 确保操作切换设置为 **Screenshot**（相机图标）。
2. 选择捕捉模式：`Region`、`Screen` 或 `Window`。
3. 点击圆形 **Capture** 按钮。

默认情况下，截图图像会自动保存到主目录下的 `Pictures/Screenshots` 文件夹中。

### 录制录屏

1. 将操作切换设置为 **Screencast**（摄像机图标）。
2. 选择要录制的区域（`Region` 或 `Screen`）。
3. 点击圆形 **Capture** 按钮开始录制。

屏幕右上角会出现红点及计时器，表示正在录制。点击红点即可停止。视频将自动保存为主目录下 `Videos/Screencasts` 文件夹中的 `.webm` 文件。

## 面向高级用户的键盘快捷键

为了更快速的捕捉，GNOME 提供了一组可直接跳过交互界面的键盘快捷键。

| 快捷键                    | 操作                                                             |
|--------------------------|------------------------------------------------------------------|
| ++print-screen++         | 打开交互式截图界面。                                                |
| ++alt+print-screen++     | 立即截取当前活动窗口的截图。                                        |
| ++shift+print-screen++   | 立即开始选择矩形区域进行截图。                                      |
| ++ctrl+alt+shift+"R"++   | 开始和停止全屏录制。                                                |

### "复制到剪贴板"修饰键

这是一项强大的生产力功能。在任何截图快捷键上添加 ++ctrl++ 键，捕捉的图像将直接复制到剪贴板，而不是保存为文件。这对于快速将截图粘贴到其他应用程序（如文档或聊天窗口）非常理想。

* ++ctrl+print-screen++：打开交互界面，但捕捉结果将存到剪贴板。
* ++ctrl+alt+print-screen++：将活动窗口截图复制到剪贴板。
* ++ctrl+shift+print-screen++：将选定区域截图复制到剪贴板。

GNOME 内置的截图和录屏工具是优雅高效设计的典范，既为新用户提供了简单、易发现的界面，也为高级用户提供了快速、基于快捷键的工作流。
