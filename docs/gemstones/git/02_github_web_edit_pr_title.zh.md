## 简介

本指南介绍了如何使用 GitHub web 界面编辑或更改 GitHub 仓库中已有 pull request (PR) 的标题。

## 问题描述

有时，PR 创建后可能需要修改标题以更好地反映当前的更改或讨论。

## 前置条件

- 一个已有的 GitHub pull request。
- 访问 GitHub web 界面或 CLI 并拥有必要的权限。

## 操作步骤

### 使用 GitHub Web 界面

1. **导航到 Pull Request**：
   - 转到 PR 所在的仓库。
   - 点击 'Pull requests' 并选择要编辑的 PR。

2. **编辑 PR 标题**：
   - 点击 PR 的标题。
   - 将出现一个可编辑的文本框。
   - 修改标题，按 ++enter++ 或点击文本框外的位置来保存更改。

## 附加信息（可选）

- 编辑 PR 标题不会影响其讨论线程或代码更改。
- 如果对 PR 标题进行了重大更改，通知协作者是良好的实践。

## 总结

按照这些步骤，您可以通过 web 界面轻松更改 GitHub 仓库中已有 pull request 的标题。
